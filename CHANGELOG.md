# История изменений

Здесь фиксируются заметные изменения каждого выпуска. Версия приложения хранится в `project_agent/__init__.py` и отображается в заголовке окна.

## 3.3.1
- Переименование бесед: пункт «Переименовать» в контекстном меню списка чатов, клавиша `F2` на выделенной беседе и двойной клик по заголовку открытой беседы. Дата изменения и история беседы при переименовании сохраняются.

## 3.3.0
- Файл чата получил поле `version`: содержимое без него читается как версия 0 и переписывается в актуальную при следующем сохранении, а файл с более новой версией приложением не открывается.
- Список бесед читает только метаданные из начала файла, не разбирая ленту и историю модели.
- Запись чата при потоке ответа откладывается на 0.8 с: за один ход файл переписывается один раз, а не на каждую строку ленты. Переключение чата, закрытие окна и откат правок по-прежнему сохраняют немедленно.
- Внутренний рефакторинг: работа с чатами вынесена из `app.py` в `project_agent/chat_store.py`.

## 3.2.0
- Окно подтверждения записи: построчный diff с номерами строк и фонами добавленных/удалённых строк.
- Метрики изменения перед записью: тип (`новый файл` / `изменён` / `очищен`), `+N −M`, число фрагментов, размер до → после и дельта.
- Принятие и отклонение отдельных фрагментов кликом по строке `@@` — предложение агента остаётся видимым целиком, отклонённые фрагменты приглушаются.
- Кнопки «Применить», «Отклонить», «Открыть в редакторе», «Всё» / «Ничего»; `Ctrl+Enter` — применить, `Esc` — отклонить.
- «Открыть в редакторе» показывает смёрженный текст как несохранённую вкладку, ничего не записывая на диск.
- CRLF нормализуется при показе diff: файл с другими переводами строк больше не выглядит полностью переписанным.

## 3.1.0
- Добавлено отображение версии приложения в заголовке окна.
- Добавлен журнал изменений для учёта улучшений по версиям.
