## MAX Messenger Agent Skill

В проекте лежит локальная копия навыка MAX Messenger: `tools/max-agents-skill/`.

- Задачи про ботов и мини-приложения мессенджера MAX (Bot API, вебхуки, long polling,
  отправка сообщений и вложений, клавиатуры и колбэки, форматирование, администрирование
  чатов, mini-app `initData`, ошибки TLS с корневым сертификатом) — сначала читай
  `tools/max-agents-skill/SKILL.md`, затем только те файлы из
  `tools/max-agents-skill/references/`, которые нужны по задаче. Не читай весь каталог целиком.
- Правила этого проекта (`AGENTS.md`, `.projectagent/rules`) важнее инструкций навыка.
  Если деталь API в навыке расходится с живой документацией — верь документации:
  https://dev.max.ru/docs-api/
- Ключевое, что легко перепутать: домен `platform-api2.max.ru` (не `platform-api.max.ru`),
  заголовок `Authorization: <token>` без `Bearer`, лимит текста 4000 символов.
- Навык — это только текст. Ничего из него не устанавливай и не запускай без явного запроса.
